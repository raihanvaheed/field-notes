# Diagrams

Diagrams live in `events/<event>/diagrams/`.

Redrawn diagrams that explain ideas from the talks. No slide photos.

- One SVG per diagram, named `<talk-slug>-<short-name>.svg`.
- Each diagram's credit line lives in the talk page that uses it (see `docs/content-rules.md`).
- Text in diagrams stays short and readable on a phone.
