# SMASH 2026: notes

Unofficial notes from **SMASH 2026**, the Symposium on Model Accountability, Sustainability and Healthcare, held at Mila in Montréal on 3–4 November 2026.

Written by Rai Vaheed, an attendee. Live page: https://raihanvaheed.dev/field-notes/smash-2026 (coming soon).

## Please read first

- **These are one attendee's notes, not official summaries.** Each page is my understanding of a talk, written up afterwards. Mistakes are mine, not the speaker's.
- **I only took notes for some sessions** (I'm only human). Sessions without notes are not included.
- **Corrections are welcome:** vaheed.raihan@gmail.com
- Official agenda: https://smashcon.org/en/agenda/

## What's here

- `agenda.yaml`: the sessions covered, with time, speaker, topic, a one-line summary and theme tags. The timeline on the live page is built from this file.
- `talks/`: one page per talk.
- `themes.md`: ideas that kept coming up across talks.
- `resources.md`: papers, tools and datasets mentioned, grouped by theme.
- `diagrams/`: diagrams recreated to explain ideas from the talks, each credited to the speaker.

## Credits

There are no photos or slides here. Where a diagram helps explain an idea, it has been redrawn and is credited to the speaker, with a link to their paper or work where one exists. All ideas belong to the speakers; any errors in retelling them are mine.
