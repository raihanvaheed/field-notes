# Field Notes

Notes from events I've attended, written up so you can get the main ideas without being there.

By Rai Vaheed. Live site: https://fieldnotes.raihanvaheed.dev (coming soon).

## Events

- **SMASH 2026**, the Symposium on Model Accountability, Sustainability and Healthcare. Mila, Montréal, 3–4 November 2026. Notes: [`events/smash-2026`](events/smash-2026)

## Please read first

- **These are one attendee's notes, not official summaries.** Each page is my understanding of a talk, written up afterwards. Mistakes are mine, not the speaker's.
- **I only take notes for some sessions** (I'm only human). Sessions without notes are not included.
- **Corrections are welcome:** vaheed.raihan@gmail.com

## How this repo is organised

- `events/<event>/`: one folder per event.
  - `agenda.yaml`: the event's details and the sessions covered, with themes.
  - `talks/`: one page per talk.
  - `themes.md`: ideas that kept coming up.
  - `resources.md`: papers, tools and pages mentioned.
  - `diagrams/`: diagrams redrawn to explain ideas, credited to the speakers.
- `events/_template/`: a starting point for a new event.
- `docs/`: how pages are written (`content-rules.md`, `format.md`, `diagrams.md`) and how to add an event (`new-event.md`).
- The website that renders these notes lives in this repo too, and is deployed to fieldnotes.raihanvaheed.dev.
